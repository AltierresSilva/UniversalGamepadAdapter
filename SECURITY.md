# Segurança

O projeto está em desenvolvimento e não oferece SLA de correção ou auditoria independente. Apenas a versão atual da branch main recebe correções; versões antigas podem exigir atualização.

Não publique exploits, credenciais, seriais ou logs privados em issues. Use **Security → Report a vulnerability** no GitHub quando o relato privado estiver habilitado. Se essa opção não estiver disponível, abra uma issue pedindo um canal privado, sem revelar detalhes técnicos sensíveis.

Informe versões, impacto, passos mínimos para reprodução e uma possível mitigação. Não altere drivers ou configurações de segurança de outras pessoas durante uma investigação. O UGA usa drivers de terceiros, que mantêm canais e ciclos próprios de suporte.
